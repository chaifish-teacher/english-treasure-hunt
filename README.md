# Lost Island · 失落之島英文尋寶冒險

這是一款為臺灣高中學生設計的英文複習遊戲。學生輸入座號與姓名，即可探索海島、沉船、古老神殿與城堡，最後開啟寶藏。以手機直向操作為優先，也可使用平板或電腦。

## 遊戲怎麼玩

- 每次隨機抽出 20 題單字（原題 10 題、新題 10 題）與 10 題文法（原題 5 題、新題 5 題）。同一場不重複，選項每次重新排列。
- 六個關卡，每次顯示五題。五題全部選完才能送出；送出後不能回頭修改。
- 每題可自行展開「Hint 提示」。單字／片語題另有完整句意翻譯，填空處保留空格；文法題提供解題方向。查看提示不影響計分，錯題挑戰也可使用。
- 初次作答不公布對錯或成績。初次答錯的題目各有一次「錯題挑戰」；全對則直接開啟寶藏。
- 最後顯示單字、文法、初次總成績、錯題挑戰及最終掌握成績。初次總成績保留，最終掌握成績另行計算。
- 所有初次答錯的題目都有可展開的答案回顧與中文解析，即使第二次已答對也會保留。
- 沒有倒數計時、排行榜或學生帳號。音效可以關閉。
- 「再次挑戰」保留姓名與座號，建立新的遊戲紀錄。「登出」清除本次身分與遊戲資料。

## 在自己的電腦執行

需要先安裝 Node.js（建議 24 LTS；Vite 亦支援 22.12 以上）。在此專案資料夾開啟終端機，依序輸入：

```sh
npm ci
npm run dev
```

`npm ci` 會按照已保存的套件版本安裝。終端機會顯示可在瀏覽器開啟的本機網址。啟動遊戲需要能連線至下方的 Google Apps Script。

## 產生正式版檔案

```sh
npm run build
```

完成後，網站檔案在 `dist/`。若要在本機檢查正式版：

```sh
npm run preview
```

本專案尚未部署或發布；這份說明不包含部署步驟。

## 成績系統在哪裡設定

唯一的 API 網址常數 `GAS_API_URL` 位於 `src/config.js`，已設定為老師提供的 Google Apps Script 網址。

前端沿用既有後端，不新增伺服器或資料庫，也不修改 Apps Script。登入使用 `action: "start"`；只有收到有效 `gameId` 才能開始遊戲。完成使用同一個 `gameId`，傳送 `action: "complete"`。

POST 的 JSON 內容刻意使用 `text/plain;charset=utf-8`，並跟隨重新導向。不要改成 `application/json`，避免不必要的 CORS 預檢。

成績無法儲存時，結果畫面與答案仍會保留，可按「重新儲存」。同一場遊戲的重試使用相同 `gameId`。遊戲未完成就關閉瀏覽器，不會送出完成請求。遊戲狀態保存在當前頁面記憶體中；重新整理或關閉頁面不會自動恢復。

正式 Google Sheet 連線尚待實際驗證：本次雲端環境的代理阻擋 Google Apps Script 網路請求（CONNECT 403），因此自動化瀏覽器測試使用模擬 API 回應，**未宣稱實際成績已寫入 Google Sheet**。正式程式一直使用真實網址。若在此雲端環境測試連線，環境網路設定需允許 `script.google.com` 與重新導向目的地 `script.googleusercontent.com`。

## 主要檔案

| 檔案或資料夾              | 用途                                  |
| ------------------------- | ------------------------------------- |
| `src/App.jsx`             | 登入、遊戲關卡、錯題挑戰與結果畫面    |
| `src/components/`         | 題目卡片、海島插畫、探險者與圖示      |
| `src/data/questions.json` | 80 題核准題庫與解析                   |
| `src/lib/game.js`         | 隨機抽題、穩定選項 ID、計分與關卡狀態 |
| `src/lib/api.js`          | 成績 API、逾時處理與重複儲存防護      |
| `src/lib/sound.js`        | 輕量合成音效，不需外部音效檔案        |
| `src/config.js`           | Google Apps Script 網址               |
| `src/styles.css`          | 手機優先版面與減少動態效果設定        |
| `tests/`                  | 邏輯、API 與瀏覽器測試                |

插畫為專案內的 SVG 與 CSS，不需要上傳圖片，也不依賴外部圖片或字型服務。

**不要隨意修改 80 題題庫。** 題目 ID、原題／新題分類、選項 ID 與答案都影響抽題和計分。正確答案依穩定選項 ID 判斷，不依畫面上的 A／B／C／D。測試內包含題庫指紋，內容變更須經核對後才可更新。

## 檢查與測試

```sh
npm test
npm run lint
npm run build
```

邏輯測試會反覆產生 1,000 場遊戲，檢查抽題比例、不重複、選項重排、計分、滿分跳過錯題挑戰及狀態鎖定。API 測試檢查請求格式、連線失敗、逾時、重複提交與重試。

完整瀏覽器測試：

```sh
npx playwright install chromium
npm run test:e2e
```

若環境已有 `/usr/bin/chromium`，測試會直接使用，不需要再下載。瀏覽器測試使用建置後的網站，因此請先執行 `npm run build`。涵蓋完整遊戲、儲存重試、再次挑戰、登出、鍵盤操作，以及 375、390、430、768、1280 像素版面。模擬 API 的測試不會新增真實 Google Sheet 資料。
